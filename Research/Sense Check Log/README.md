# Sense Check Log

Judges want "the tester quote that changed your build." Log every check here: one file per check, using the template below.

| Check | Block | Time | Status | File |
|---|---|---|---|---|
| 1 | Test the idea | 12–1 PM | Sent (VentureSauce pitch deck, then called "Filing Delta") | `check-1-idea.md` |
| 2 | Show what you built | 3–4 PM | Not run | `check-2-build.md` |
| 3 | Your question | 6–7 PM | Not run | `check-3-question.md` |
