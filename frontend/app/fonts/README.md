# Fonts

`BespokeSerif-Regular.woff2` and `BespokeSerif-Medium.woff2`: **Bespoke Serif** by the Indian Type Foundry (ITF), from [Fontshare](https://www.fontshare.com/fonts/bespoke-serif). The ITF Free Font License ([terms](https://fontshare.com/terms)) asks that ITF be credited by name as the owner of the trademarks and copyright. This file is that credit.

The fonts are bundled locally, so the side panel works offline during the demo. Bespoke Serif has **old-style figures only**: there are no lining or tabular OpenType features.
